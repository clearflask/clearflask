# ClearFlask 2.7.1 release

Date: 2026-10-26. Participants: Matus (board), Codex.

Matus explicitly requested a new ClearFlask release after the production security
fixes. Published patch version 2.7.1 from tested application commit 54a48d5d.
The release includes AI project/conversation authorization, registration CAPTCHA,
GitLab OAuth provider binding, superadmin account deletion and session/CAPTCHA
handling, plus packaging and CI improvements since 2.7.0.

Validation: CI=true all-module clean install passed with 390 Java tests and four
frontend regressions, production frontend/Connect compilation and packaging.
Only local Docker image builds were skipped; release CI built and published the
actual multi-platform images.

Release workflow 40384908615 and its Helm publication job both succeeded.
The GitHub release was published with upgrade notes. Verified versioned server
and Connect registry manifests include linux/amd64 and linux/arm64; both Helm
packages are attached and the Helm repository index includes 2.7.1.

Release: https://github.com/clearflask/clearflask/releases/tag/2.7.1
Workflow: https://github.com/clearflask/clearflask/actions/runs/40384908615

This publishes the self-hosted distribution. Production SaaS already runs the
application fixes; no additional SaaS deployment was required for the release.
