# ClearFlask 2.7.2 patch release

Date: 2026-10-31. Participants: Matus (board), Codex.

Matus explicitly authorized a patch release after the subscriber notification
batching fix was deployed. Released version 2.7.2 from application commit
`a6d1043f` and documentation commit `978cd5ee`; release commit `b85bc7a9`.
The tag contains the tested fix. Other changes since 2.7.1 include superadmin
registration controls, their dashboard-admin-only scope correction, and simpler
account-deletion confirmation.

Validation before shipping: full CI=true all-module clean install passed with
401 Java tests, frontend regression tests, frontend/Connect production compilation,
and packaging. Local Docker images were skipped; release CI built and published
the actual images. Release workflow 41204112880 and its Helm publication job both
succeeded.

Verified versioned server and Connect image manifests contain linux/amd64 and
linux/arm64. Both Helm packages are attached, and the Helm repository index
contains version 2.7.2. Published the GitHub release with upgrade notes.

Release: https://github.com/clearflask/clearflask/releases/tag/2.7.2
Workflow: https://github.com/clearflask/clearflask/actions/runs/41204112880

The production SaaS already serves the subscriber fix; this release publishes
the self-hosted distribution. No additional SaaS rollout was needed.
